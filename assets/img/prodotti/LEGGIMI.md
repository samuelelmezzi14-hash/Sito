# Foto dei prodotti

Metti qui le foto dei peluche fornite dal tuo fornitore di dropshipping.
Il nome del file deve essere **l'`id` del prodotto + `.jpg`** (vedi `assets/js/data.js`), ad esempio:

| Prodotto | File |
|---|---|
| Amuseable Albero di Natale | `amuseable-albero-di-natale.jpg` |
| Renna Timida | `renna-timida.jpg` |
| Orsetto Bartolomeo col Maglione | `orsetto-bartolomeo-maglione.jpg` |

- Formato consigliato: quadrato, almeno 1000×1000 px, sfondo chiaro.
- Se la foto esiste viene mostrata nelle schede e come prima immagine della pagina prodotto;
  altrimenti resta l'illustrazione disegnata a mano.
- Per usare un altro nome o un URL esterno (es. CDN del fornitore) aggiungi `foto: '...'` al prodotto in `data.js`.
- Usa solo foto che hai il diritto di usare (fornite dal distributore o scattate da te).
